# Cancha y Casa

App web (un solo archivo, `index.html`) para entrenamiento de fútbol, alimentación y seguimiento de InBody.

- **Entreno:** martes y jueves en cancha (velocidad, agilidad, resistencia); lunes, miércoles y viernes en casa con barra y bici de spinning. Casillas para marcar cada ejercicio y campo para anotar los kilos usados.
- **Comida:** calorías y macros según el tipo de día, contador de agua y menú sugerido con comida mexicana.
- **InBody:** captura de mediciones (Salud Digna), cambios desde la primera medición, gráfica de tendencia e historial.
- **Perfil:** edad, peso, estatura, meta y déficit; respaldo y restauración de datos.

Los datos se guardan en el navegador (localStorage). Abre `index.html` en cualquier navegador.
